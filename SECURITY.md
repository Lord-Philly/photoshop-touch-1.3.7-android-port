# Segurança e tratamento de artefatos

- Não faça commit de APK, AAB, SWF, ANE, JAR, SO ou outros binários proprietários.
- Mantenha os artefatos originais fora do repositório e registre somente hashes e metadados necessários.
- Remova tokens, certificados privados, chaves de assinatura, credenciais e endpoints secretos dos relatórios.
- Teste somente aplicativos e dispositivos para os quais você tenha autorização.
- Não use este projeto para burlar DRM, licenças, autenticação ou controles de acesso.
